铸壳工具链（ForgeShell）· s2a —— 常用帮助（--help）
================================================================================
本档给出全部选项、全部环境变量、三种产物、加密机制、语言覆盖、退出码与已知缺陷。
要「绝对完整」（字节布局、尾部字段表、运行时架构、模拟器内部、加固内部、排错）：
    s2a --help-full
构建、自检与回归、开发笔记：
    s2a --help-dev

【一】它是什么
--------------------------------------------------------------------------------
  · 把 shell 脚本**提前编译**成 aarch64 纯静态 ELF：产物没有 PT_INTERP、没有
    .dynamic，不依赖目标机上的 libc/shell，拷过去就能跑（自带 musl 运行时）。
  · 内置 AArch64 模拟器（-r）：在没有 qemu 的机器上也能运行/调试产物。
  · 自备两个工具：qemu-aarch64 静态版与 dash 0.5.12（自编静态 ash）。
    ⚑ 这两个工具**只在 s2a 自己身上**（s2a 约 2.89MB），**产物一律不带工具**。
      用 `s2a ash …` / `s2a qemu …` 调用；写 `./产物 ash …` 是错的，产物里没有 ash。
  · 三种产物形态：普通编译产物 / -easy 最简产物 / --only-enc 整文件加密产物。
  · 语言目标：**POSIX 追求完整**；GNU 扩展只做部分。
  · 一条分界：不给口令 = 混淆；给口令 = 真加密（见【六】）。

【二】用法
--------------------------------------------------------------------------------
  s2a [选项] <脚本>                       编译脚本
  s2a [选项] -e '<脚本内容>'              直接编译命令行的文本
  s2a -r <产物> [参数…]                   用内置模拟器解释执行
  s2a -qemu <产物> [参数…]                用内嵌/外部 qemu 执行
  s2a -X|--iso <产物> [参数…]             交给外部 iso 项目执行
  s2a -easy -o out.elf <脚本>             最简模式
  s2a --only-enc <输入.elf> <输出.elf>    整文件加密
  s2a -h | --help | --help-full           帮助（快 / 常用 / 完整）
  s2a --help-dev                          构建、自检与开发笔记
  s2a -v | --version                      版本
  s2a -license                            许可证（大小写不敏感）
  s2a ash -c '命令'                       用 s2a 自带的 dash 执行命令
  s2a ash 脚本.sh 参数…                   用 s2a 自带的 dash 执行文件
  s2a qemu -L … ./prog                    用 s2a 自带的 qemu 执行别的程序

【三】全部选项
--------------------------------------------------------------------------------
输入输出
  -o <文件>             产物路径（缺省按输入名推导；-e 模式缺省 a.elf）
  -e '<文本>'           直接给脚本文本
  -K                    保留中间产物（.ast/.ir/.code.bin/.data.bin …，不自动清理）
  -s                    strip 产物（去符号表）

优化与调试
  -O0 … -O4             优化级别（-F 会顺带拉到 4）
  -g                    等价于 -g2
  -g1                   阶段统计（词法/语法/代码生成规模、模板符号数、段布局）
  -g2                   AST 转储
  -g3                   IR / 优化过程
  -g4                   机器码（反汇编视图）
  -g5                   全量（含防护细节、随机源、池/代码摘要）

保护与加密（机制细节见【六】）
  -P                    防护等级 2：字符串池 AES-256-CTR 加密、代码与池 SHA-512
                        完整性自检、反调试（多层交叉验证）
  -F                    防护等级 3 + 优化 4（最全保护）
  --password '<口令>'   口令锁（编译期与运行期都支持；不给或给错 → 退出码 70）
  --password=<口令>     同上，等号写法
  --password-env <变量> 从环境变量取口令（未设置或为空 → 70）
  --password-file <文件> 从文件取内容当口令（内容原样 = cat；echo 会多换行，
                        建议 printf）；下划线写法 --password_file 也行
                        （三者都没给时兜底读 S2A_PASSWORD）
  --anti-action <策略>  检测到调试/注入迹象时的动作：
                          warn(默认)  一行警告，继续
                          report      打印完整检测表，继续
                          silent      静默继续
                          fake        假装一切正常（状态码改 0）
                          delay       睡 2 秒再继续
                          stop        停止执行（退出）
  --no-tools            兼容保留，**无作用**（早期版本用它关闭"产物内嵌工具"；
                        现在产物一律不带工具，所以它不再影响任何行为）

形态切换
  -easy                 最简模式：不解析、不生成代码，产物 = 外壳 + 内嵌 dash +
                        脚本正文（约 183KB）。dash 能跑就能出产物。
  --only-enc <in> <out> 整文件加密（任意 ELF）：外壳 + AES-256-CTR 密文 + 128 字节
                        尾部。给了口令就是**运行期门禁**：运行时必须再给同一口令
                        才能解密，不给/给错 → 退出码 70

运行模式
  -r                    内置模拟器解释执行（遇未实现指令/访存故障默认自动回退
                        内嵌 qemu 从头重跑）
  -qemu, --emu-qemu     直接用 qemu 执行（跳过模拟器）
  --emu-own             只用内置模拟器，绝不回退（调试解释器用；报 132/139）
  --no-fallback         不回退，遇问题直接失败（与 --emu-own 同为"关回退"开关）
  --emu-trace           打印模拟器指令轨迹（量很大，配合窗口变量用）
  -X, --iso             走 iso 项目

其它
  -h / --help / --help-full / --help-dev  四档帮助（本档是第二档）
  -v / --version                          版本与作者
  -license                                打印 MIT 许可证全文

【四】全部环境变量
--------------------------------------------------------------------------------
编译期
  /dev/random                      池加密密钥、校验料、随机种子的唯一来源
                                   （所以同一份脚本每次编译的密文都不同，
                                     也没有任何硬编码密钥可被提取）

运行期（产物与外壳）
  S2A_PASSWORD=<口令>              口令兜底来源（没给 --password* 时读它）
  S2A_NO_ANTIDEBUG=1               彻底关闭反调试：**连探测都不做**
  S2A_ANTIDEBUG=1                  打印完整检测表
  S2A_ANTIDEBUG_AGGRESSIVE=1       允许主动 ptrace 探测（在子进程里做，不自锁）
  S2A_LOCK_DEBUG=1                 口令锁/解密过程诊断
  S2A_VAR_DEBUG=1                  变量表定义/释放/作用域跟踪
  S2A_DEBUG_TRACE=<值>             反调试检测项之一（预载类环境变量）
  S2A_TOOL_DIR=<目录>              工具解出目录（第一优先，s2a ash/qemu 用）
  TMPDIR=<目录>                    工具解出目录（第二优先；其后 /data/local/tmp、/tmp）
  S2A_NO_MEMFD=1                   不用匿名内存页（memfd）执行，直接落盘 exec

内置模拟器（都只在指定窗口输出，避免刷屏）
  S2A_EMU_TRACE_PC=lo:hi           只打印该 PC 窗口内的指令轨迹
  S2A_EMU_WHO=lo:hi                打印 PC 落在 [lo,hi) 内的指令归属
  S2A_EMU_CALLWATCH=lo:hi          记录该区间内的调用目标
  S2A_EMU_WATCH=起[:止]            内存写监视（只报落在该区间的写）
  S2A_EMU_REGS=1                   轨迹行追加全部通用寄存器
  S2A_EMU_VREGS=1                  轨迹行追加向量寄存器（调 SIMD 用）
  S2A_EMU_OVERLAY=<目录>           覆盖层根目录（第一优先，见下）
  S2A_TMPDIR=<目录>                覆盖层/临时目录（第二优先，其后 TMPDIR）
  S2A_EMU_MAX_STEPS=<步数>         步数上限（默认 3000 万，超了退出码 124）
  S2A_EMU_SKIP_UNIMPL=1            未实现指令当空操作继续（批量差分用，一次收齐）
  S2A_EMU_ENV_STRICT=1             用固定 3 项环境（默认像真 shell 一样用真实环境）
  S2A_EMU_NO_SEGCHECK=1            不校验段权限（关闭"只读段禁写"的严格面）
  S2A_EMU_NO_HOLECHECK=1           不把未映射空洞判为越界
  S2A_EMU_DBG / S2A_EMU_DEBUG=1    个别指令（movz/movk、逻辑运算）的逐条诊断

编译期/运行期用 qemu 时的查找（-qemu 与回退路径）
  S2A_QEMU=<路径>                  指定外部 qemu-aarch64 可执行文件
  S2A_QEMU_DIR / S2A_QEMU_DIRS     内嵌 qemu 解出目录
  S2A_QEMU_FORCE_EMBEDDED=1        只用内嵌 qemu，不找机器上的

【五】三种产物形态
--------------------------------------------------------------------------------
  A 普通编译产物   约 450KB（典型 451,008 字节量级，随脚本大小变化）
      模板 ELF（静态 musl）+ 追加两个 LOAD 段（RX：机器码/只读数据；RW：可写数据），
      并 patch 模板里的 rc_user_main 指向生成代码入口。
      **不含任何工具**。用法：./产物 [参数…]
  B -easy 产物     88,184（外壳）+ 94,816（ash）+ 脚本正文 + 128（尾部）≈ 183KB
      用法：./产物 [参数…]（外壳解出 ash 与脚本后 exec `ash 脚本 参数…`）
  C --only-enc 产物  88,184（外壳）+ 原文件长度（密文）+ 128（尾部）
      用法：./产物 [参数…]（解密到匿名内存页后 fexecve；argv 原样透传）

【六】口令与加密（两套机制，别混）
--------------------------------------------------------------------------------
⚑ 分界线：**不给口令 = 混淆，给口令 = 真加密**。
  不带口令的 -P / -F / --only-enc：密钥原料（seed / nonce / salt）就存在产物或
  文件里，拿到文件的人可以自行解开 —— 它的价值是"不是明文"（防 strings、防顺手
  一看、防特征扫描）。只有 --password / --password-env / --password-file /
  S2A_PASSWORD 才让密钥离开文件。

■ 机制一：字符串池加密（-P / -F 的编译产物，防的是 strings）
  · 算法：AES-256-CTR。
  · 密钥：全部来自 /dev/random 的 64 字节 seed，经 kdf_strong() 域分离派生
    （purpose 标签 "protect-pool" / "protect-check"），**不硬编码**。
  · 完整性：代码段与字符串池各带 SHA-512 摘要，启动时自检。
  · 口令锁（--password）：口令走 PBKDF2-HMAC-SHA256，盐 = 产物池的前 16 字节
    （每个产物不同），迭代 5000 次（KDF v2），密钥材料 64 字节。
    口令不对 → 池无法还原 → 退出码 70。

■ 机制二：整文件加密（--only-enc，产物 = 外壳 + 密文 + 尾部）
  · 算法：AES-256-CTR；尾部魔数 S2ALAU02（旧文件 S2ALAU01 仍可运行）。
  · 不给口令：key = kdf_strong(seed, "onlyenc-seed", nonce)，seed/nonce 存在尾部
    → 属混淆（拿到文件的人能自行解开）。
  · 给了口令：key = PBKDF2-HMAC-SHA256(口令, 尾部 16 字节随机盐, 5000 次)
    → 属真加密 + **运行期门禁**：运行时必须再给同一口令，否则 70；
    解密结果不是 ELF 也判口令错（70）。
  · 运行时把密文解到匿名内存页（memfd）后 fexecve；内核不允许时兜底落盘 exec
    并在退出前删除。
  · 多层嵌套可以：外层解出口令会导出 S2A_PASSWORD 给内层，且只吃掉第一个口令
    参数（后续留给内层），所以同口令给一次、不同口令按层顺序给
    `./x.enc --password 外层 --password 内层`。
  · 注意：CTR 是流模式，改密文里一个字节只会坏对应那一个明文字节，不会被检测
    —— **能防看，不防改**。

【七】语言覆盖
--------------------------------------------------------------------------------
POSIX（目标：完整；308 条自检逐条与 bash/dash 对拍）
  引用与转义、参数展开全套（${v} ${#v} ${v-w} ${v:-w} ${v=w} ${v:=w} ${v?w}
  ${v:?w} ${v+w} ${v:+w} ${v#p} ${v##p} ${v%p} ${v%%p}）、特殊参数（$* $@ $# $?
  $- $$ $! $0 $1…）、算术展开（** 赋值 三目 自增自减 逗号）、命令替换（`` ` `` 与
  $( )，可嵌套、可含 case）、字段切分（IFS 全规则、$@ 语义、引号内不切分）、
  路径名展开（* ? [ ]，引号内元字符不通配）、重定向（< > >> <> >| n< n> >& <&
  >&- << <<- <<< 及复合命令重定向）、管道与 !、&& || ; &、if/elif/else、
  case（;; ;& ;;&）、for/while/until、break/continue n、函数与 local、return、
  子 shell 与 { } 分组、特殊内建（: . eval exec exit export readonly return
  set shift times trap unset）、普通内建（cd -P/-L/CDPATH/OLDPWD/PWD、
  command -v/-V、echo、printf、pwd、read -r/-d/-n、test/[ 含 ! -a -o 与括号、
  getopts、kill、umask、unset -f、wait、jobs、times、type）、set 全选项
  （-a -b -C -e -f -h -m -n -u -v -x 与 -o 名字形式）、trap 信号/EXIT、
  非交互语义（后台与前台同进程组；shell 自己忽略 SIGINT/SIGQUIT，子进程恢复默认）

GNU 扩展（**部分**）
  支持：[[ ]] 及其通配/正则、(( )) 算术命令、$(( )) 里嵌 $( )、
        ${v:off:len}、${v^} ${v^^} ${v,} ${v,,}、${v/p/r} ${v//p/r}、${!v}、
        $'…'、<<< here-string、&> 与 &>>、函数覆盖内建
  不支持：数组/关联数组、shopt、{1..3} 花括号展开

与 bash 的已知差异（都实测记录）
  · `$-` 只反映本工具链真正支持的选项（没有 bash 的 h/B）
  · `${#*}`/`${#@}` 按 POSIX/dash 取 $* 拼接长度（bash 给的是参数个数）
  · 不做作业控制（set -m）：POSIX 非交互行为

【八】退出码
--------------------------------------------------------------------------------
  0        成功（运行模式下 = 脚本自身退出码）
  1–125    脚本自身退出码；编译模式下 1 = 编译失败
  2        用法错误
  70       口令缺失/错误（含 --only-enc 解出来不是 ELF）
  73       解不出内嵌工具（没有可写目录；用 S2A_TOOL_DIR 指定）
  124      模拟器步数上限（S2A_EMU_MAX_STEPS，默认 3000 万步）
  126      命令不可执行（s2a ash/qemu 解出后 execv 失败也算）
  127      命令未找到（与 POSIX 一致）
  132      模拟器遇到未实现指令（--emu-own / --no-fallback 时）
  139      访存越界/段错误（模拟器判定）

【九】已知缺陷
--------------------------------------------------------------------------------
  · 模拟器未实现「SIMD 单车道存储」st1 {v?.b|h|s|d}[i], [xn]（极罕见；
    默认会自动回退 qemu，--emu-own 时报 132）。同族单车道装载已支持。
  · 模拟器覆盖通用寄存器指令集 + 常用 NEON/FP 子集；SVE/SME、CRC32、
    加密扩展与部分罕见 SIMD 形式未实现（同样触发回退）。
  · 模拟器原子独占访存是单线程语义：只保证「同地址 + 同尺寸」的独占存储成功。
  · 反调试在本机会误报：宿主终端/看门狗会挂 ptrace → TracerPid≠0；
    默认只 warn，不影响运行（要安静用 --anti-action silent）。
  · qemu 回退是「从头重跑」，且不走模拟器的覆盖层虚拟文件系统。
  · -K 的中间产物与模拟器覆盖层目录不会自动清理。
  · --only-enc 的密文被改动不会被发现（CTR 流模式，见【六】）。

【十】常见故障
--------------------------------------------------------------------------------
  启动后 [1]+ Stopped / 卡住     旧产物可能 ptrace 自锁；用本版重建产物
                                  应急：运行时 S2A_NO_ANTIDEBUG=1
  退出码 70                       口令缺失或错误（--only-enc 解出非 ELF 同理）
  退出码 73（s2a ash/qemu）       解不出内嵌工具，没有可写目录；
                                  设 S2A_TOOL_DIR=/data/local/tmp 后重试
  ./产物 ash -c '…'               做不到：**产物里没有 ash**，用 s2a ash -c '…'
  退出码 132 / 139                未实现指令 / 访存故障（--emu-own 时不去回退）
  体积在意                        用 -s（strip）、-O4、或 -easy（约 183KB）；
                                  --no-tools 无作用，别指望它省体积
