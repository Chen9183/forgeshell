这份文档把整套东西讲透：从"编译一个脚本"到"产物尾部每一个字节是什么"。
要构建、自检、开发笔记：s2a --help-dev。

  ⚑ 一条分界线（先记住）：**不给口令 = 混淆，给口令 = 真加密**。
  不带口令的 -P / -F / --only-enc：密钥原料（seed / nonce / salt）就存在产物或
  文件里，拿到文件的人可以自行解开 —— 它的价值是"不是明文"。
  只有 --password / --password-env / --password-file / S2A_PASSWORD 才让密钥离开
  文件（PBKDF2-HMAC-SHA256 派生 + 运行期门禁）。

  ⚑ 另一条：**工具只在 s2a 里，不在产物里**。
  qemu 与 dash 链在编译器 s2a 身上，用 `s2a ash …` / `s2a qemu …` 调用；
  产物只含你编译进去的东西（普通产物约 450KB，不含任何工具）。

【1】一句话定位与能力边界
--------------------------------------------------------------------------------
铸壳 = 把 shell 脚本"铸"成 aarch64 的纯静态 ELF。产物：
  · 无 PT_INTERP、无 .dynamic、无外部依赖 —— 自带 musl 运行时，拷到任何
    aarch64 Linux/Android 上直接跑；
  · 可选加固：字符串池 AES 加密 + 代码/数据 SHA-512 自检 + 反调试 + 口令锁；
  · 可选整文件加密：产物自身变成"外壳 + 密文"，运行时解密到匿名内存页再执行。
编译器 s2a 自己则是个"工具箱"：内嵌 qemu 与 dash，并带一个 AArch64 模拟器。

能力边界（先说清楚，免得期待错位）：
  · 语言目标 = POSIX 追求完整 + GNU 部分扩展。数组、shopt、{1..3} 这类不做。
  · 内置模拟器覆盖通用寄存器指令集 + 常用 NEON/FP 子集，不是全指令集模拟器；
    遇到没实现的形式会自动回退到内嵌 qemu（除非显式 --no-fallback / --emu-own）。
  · 这是编译型工具链，不是交互式 shell；不作为登录 shell 使用。
  · 不带口令的加密只是混淆（见开头的分界线）。

【2】五分钟上手
--------------------------------------------------------------------------------
1) 编译并运行
     s2a -o hello.elf hello.sh
     ./hello.elf

2) 用 s2a 自带的工具（工具在 s2a 身上，产物不带）
     s2a ash -c 'echo 内嵌 dash 在跑; echo $((6*7))'
     s2a qemu --version

3) 最简模式（不编译脚本，直接用内嵌 dash 执行）
     s2a -easy -o easy.elf hello.sh
     ./easy.elf

4) 把任意 ELF 加密（产物、ash、别的程序都行）
     s2a --only-enc easy.elf easy.enc
     ./easy.enc                      # 解密到匿名内存页后执行
     s2a --only-enc easy.elf p.enc --password 'mypw'   # 真加密 + 运行期门禁
     ./p.enc --password mypw         # 不给口令 → 退出码 70

5) 加固编译
     s2a -F --password 'mypw' -o hard.elf hello.sh
     ./hard.elf --password mypw      # 口令不对 → 退出码 70

6) 没有 qemu 的机器上运行/调试
     s2a -r hello.elf                # 内置模拟器；缺指令自动回退
     s2a -r --emu-own hello.elf      # 只用模拟器，绝不回退（调试用）

【3】命令行完全参考
--------------------------------------------------------------------------------
■ 输入与输出
  s2a [选项] <脚本>
      最常见用法。脚本可以是任意 POSIX shell 脚本（含部分 GNU 扩展）。
  -o <文件>
      指定产物路径。缺省按输入名推导；-e 模式下缺省 a.elf。
  -e '<脚本内容>'
      直接从命令行取脚本，不读文件。适合一行脚本与临时验证。
  -K
      保留中间产物（AST/IR/机器码/数据段等），便于事后检查；不会自动清理。
  -s
      strip：去掉产物符号表，体积更小；代价是调试符号全无（gdb 里看不到函数名）。
      注意：模板与产物的 rc_* 符号是编译期用的，strip 只影响产物侧的符号表。

■ 优化与调试输出
  -O0 / -O1 / -O2 / -O3 / -O4
      优化级别。级别越高产物越小/越快，编译越慢；-F 会顺带把优化拉到 4。
  -g（等价 -g2）
  -g1  阶段统计（词法/语法/代码生成规模、模板符号数、段布局）
  -g2  AST 转储（节点树、词片段种类、重定向 op）
  -g3  IR / 优化过程
  -g4  机器码（反汇编视图）
  -g5  全量（含防护细节、随机源、池/代码摘要）

■ 保护与加密
  -P
      防护等级 2：字符串池 AES-256-CTR 加密；代码段与池各带 SHA-512 摘要；
      反调试多层交叉验证（见【9】）。密钥材料全部来自 /dev/random，不硬编码。
  -F
      防护等级 3 + 优化 4。最全保护；产物启动时做完整性自检。
  --password '<口令>' / --password=<口令> / --password-env <变量> / --password-file <文件>
      口令锁：PBKDF2-HMAC-SHA256(口令, 盐 = 产物池前 16 字节, 5000 次迭代)
      派生密钥（KDF v2）。文件方式取文件内容原样（等价 cat；echo 会多换行，
      建议 printf 写入）；都没给时兜底读环境变量 S2A_PASSWORD。
      编译期与运行期都支持；口令不给/不对 → 退出码 70。
      注意口令不要写在会被记录的地方。
  --anti-action <策略>
      warn    默认。命中调试/注入迹象时打一行（说清是哪一项），继续执行。
      report  打完整检测表（check 数、命中项、TracerPid、父进程名等），继续。
      silent  静默继续，什么也不打。
      fake    假装一切正常（把状态码改成 0）。
      delay   睡 2 秒再继续。
      stop    停止执行。
      —— 安卓终端/root 环境 TracerPid 非 0 是常态，属于误报，warn 不影响运行。
  --no-tools（兼容保留，无作用）
      早期版本用它来关闭"产物内嵌工具"。现在产物一律不带工具，故该开关不再
      影响任何行为（工具只存在于 s2a 里）。

■ 形态切换
  -easy
      最简模式：不解析、不生成代码。产物 = 外壳 + 内嵌 dash + 脚本正文（约 183KB）。
      适用：dash 能跑但本工具链不支持的语法（花括号展开、${v:off:len} 等）。
      -easy 产物不做自己的脚本加密；需要加密请交给 --only-enc（【12】）。
  --only-enc <输入.elf> <输出.elf> [--password 口令]
      整文件加密：外壳 + AES-256-CTR 密文 + 128 字节尾部索引。任意 ELF 都可以
      （本工具链产物、系统 ash、你自己的程序）。见【12】。

■ 运行模式
  -r
      用内置 AArch64 模拟器解释执行产物（"不真实执行"：syscall 走虚拟文件系统，
      可观察产物做了什么）。遇到未实现指令或访存故障默认自动回退到内嵌 qemu
      从头重跑一遍（结果正确，只是多跑一遍）。
  -qemu, --emu-qemu
      直接指定用 qemu 执行（跳过模拟器）。
  --emu-own / --no-fallback
      关掉自动回退（两者都是"关回退"开关，语义侧重不同）。调试解释器时用；
      遇到未实现的东西直接报 132/139，而不是被回退掩盖。
  --emu-trace
      打印模拟器执行的指令轨迹（量很大，配合 S2A_EMU_TRACE_PC / S2A_EMU_WHO /
      S2A_EMU_CALLWATCH 的窗口变量用，否则会刷屏）。
  -X, --iso
      把执行交给外部 iso 项目。

■ 其它
  -h / --help / --help-full / --help-dev   四档帮助（本档是第三档）
  -v / --version                           版本与作者
  -license                                 打印 MIT 许可证全文（大小写不敏感）

【4】环境变量完全参考
--------------------------------------------------------------------------------
■ 编译期
  /dev/random
      池加密密钥、完整性校验料、随机种子的唯一来源。所以同一份脚本每次编译
      的密文都不同；也意味着没有任何硬编码密钥可被提取。
■ 运行期（产物与外壳）
  S2A_PASSWORD=<口令>
      口令兜底来源；也是嵌套加密时外层传给内层的通道（见【12】）。
  S2A_NO_ANTIDEBUG=1
      彻底关闭反调试：**连探测都不做**（不是"只关动作"）。排查环境误报时的
      第一选择。
  S2A_ANTIDEBUG=1
      打印完整检测表（默认只有命中时打一行 warn）。
  S2A_ANTIDEBUG_AGGRESSIVE=1
      允许主动 ptrace 探测。探测在**子进程**里做，主进程不会被挂住。
  S2A_LOCK_DEBUG=1
      口令锁与解密过程诊断。
  S2A_VAR_DEBUG=1
      变量表跟踪：定义/释放/作用域进出（排查变量作用域问题时用）。
  S2A_DEBUG_TRACE=<值>
      反调试判定的预载类环境变量之一（与 LD_PRELOAD/LD_AUDIT 同类）。
  S2A_TOOL_DIR=<目录>
      内嵌工具（qemu/ash）解出的第一优先目录。没有可写 /tmp 的环境用它。
  TMPDIR=<目录>
      解出的第二优先目录；其后是 /data/local/tmp，最后 /tmp。
  S2A_NO_MEMFD=1
      不用匿名内存页（memfd）执行，直接落盘 exec。
  S2A_QEMU=<路径> / S2A_QEMU_DIR / S2A_QEMU_DIRS / S2A_QEMU_FORCE_EMBEDDED=1
      指定外部 qemu、指定内嵌 qemu 解出目录、强制只用内嵌 qemu。
■ 内置模拟器（都只在指定窗口输出，避免刷屏）
  S2A_EMU_TRACE_PC=lo:hi     只在该 PC 窗口内打印指令轨迹
  S2A_EMU_WHO=lo:hi          打印 PC 落在 [lo,hi) 内的指令归属
  S2A_EMU_CALLWATCH=lo:hi    记录该区间内的调用目标
  S2A_EMU_WATCH=起[:止]      内存写监视（只报落在该区间的写）
  S2A_EMU_REGS=1             轨迹行追加全部通用寄存器
  S2A_EMU_VREGS=1            轨迹行追加向量寄存器（调 SIMD 用）
  S2A_EMU_OVERLAY=<目录>     覆盖层根目录（第一优先；其后 S2A_TMPDIR、TMPDIR）
  S2A_TMPDIR=<目录>          覆盖层/临时目录（第二优先）
  S2A_EMU_MAX_STEPS=<步数>   步数上限（默认 3000 万；超了退出码 124）
  S2A_EMU_SKIP_UNIMPL=1      未实现指令当空操作继续（批量差分用，一次收齐缺失）
  S2A_EMU_ENV_STRICT=1       用固定 3 项环境（默认像真 shell 一样用真实环境）
  S2A_EMU_NO_SEGCHECK=1      不校验段权限（关掉"只读段禁止写"的严格面）
  S2A_EMU_NO_HOLECHECK=1     不把未映射空洞判为越界
  S2A_EMU_DBG / S2A_EMU_DEBUG=1  个别指令（movz/movk、逻辑运算）的逐条诊断
  —— 模拟器刻意贴近内核严格面（RELRO 只读、第 0 页不映射、空洞越界），
     目的是让"真机会崩、模拟器却静默通过"的 bug 早点暴露。

【5】三种产物的字节布局
--------------------------------------------------------------------------------
■ 形态 A：普通编译产物（约 450KB）
  ┌──────────────────── 模板 ELF（静态 musl，代码段基址 0x100000）────────────┐
  │  · 编译期解析模板符号表 → 拿到运行时函数（rc_*）的绝对地址               │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  追加 PT_LOAD #1（RX）：生成的机器码 + 只读数据（字符串池、AST 镜像）    │
  │  追加 PT_LOAD #2（RW）：运行期可写数据（变量表、栈外状态）               │
  │  patch 模板里的 rc_user_main 指针 → 生成代码入口                         │
  └──────────────────────────────────────────────────────────────────────────┘
  注意：产物**不带** qemu/ash（工具在 s2a 里）。
  两条硬规则（都是踩坑得来的）：
   ① 程序头表必须落在第一个 LOAD 段的文件范围内：内核/加载器用
      AT_PHDR = 段基址 + (e_phoff − 段文件偏移) 定位它，否则启动即崩。
   ② 可执行段不得携带 bss：filesz 与 memsz 都要页对齐，否则部分加载器报
      "PT_LOAD with non-writable bss" 之类错误。
■ 形态 B：-easy 产物（约 183KB）
  [外壳 ELF(88,184)] [ash blob(94,816)] [脚本正文(N)] [128 字节索引]
  外壳自己不带脚本加密；要加密把它交给 --only-enc（形态 C）。
■ 形态 C：--only-enc 产物
  [外壳 ELF(88,184)] [AES-256-CTR 密文(=原文件长度)] [128 字节索引]
  密文里就是原 ELF 的字节；运行时解密到内存后 fexecve，文件本身不含明文。

【6】尾部与外壳格式（128 字节字段表）
--------------------------------------------------------------------------------
■ 工具索引：已移除
  早期版本在产物尾部挂过 [qemu][ash] + "S2ATOOL1" 索引，现在**不再挂**
  （工具只存在于 s2a 里）。老产物仍能跑，但它里面的工具索引不再被使用。
■ 外壳索引（形态 B/C，128 字节）
  文件末尾 128 字节：
    偏移   长度  含义
    0      8     "S2ALAU02"（v2；-easy 用 "S2ALAU01"）
    8      8     mode：0 = easy，1 = enc
    16     8     off1（easy: ash 偏移 / enc: 密文偏移）
    24     8     len1
    32     8     off2（easy: 脚本偏移 / enc: 未用）
    40     8     len2
    48     32    seed（无口令时 key = kdf_strong(seed, "onlyenc-seed", nonce)）
    80     16    nonce
    96     16    salt（有口令时 PBKDF2 的盐）
    112    4     pw_flag（1 = 该产物带运行期口令门禁）
    116    4     iters（PBKDF2 迭代次数）
    120    8     "S2AEND02"（旧文件是 "S2AEND01"）
  旧 v1 尾部（S2ALAU01/S2AEND01）仍可运行：enc 的密钥是
  SHA-256(seed[0:32] 与 SHA-512(口令) 异或)，用于兼容早期产物。
  easy 模式：解出 ash 与脚本 → exec `ash <脚本> <用户参数…>`
  enc  模式：解密密文 → 匿名内存页（memfd）→ fexecve（argv 原样透传）；
             内核对 memfd 执行有限制时兜底写临时文件 exec，退出前删除。
■ 工具解出策略（s2a ash / s2a qemu / -r 回退）
  目录顺序：$S2A_TOOL_DIR → $TMPDIR → /data/local/tmp → /tmp。
  文件名按内容长度做键（s2a-ash-94816 等），已存在且可执行就直接用；
  写入走 `目标名.tmp<pid>` 再 rename（原子），避免半个文件被当缓存。

【7】运行时架构与两种执行引擎
--------------------------------------------------------------------------------
■ 编译产物路径
  脚本 → 词法/语法（common/parse.c）→ AST → 代码生成（compiler/codegen.c）
  → 机器码 + 只读/可写数据 → 与模板 ELF 拼装（compiler/image.c + elf.c）。
  运行期只有执行：没有解析开销，启动即跑。
■ 解释器路径
  命令替换 $( )、eval、source/. 里的脚本，运行期用**同一套 parse.c**
  （它被编译进运行时映像）解析后解释执行 —— 语法与编译期完全一致，
  不会出现"编译能过、eval 报错"的割裂。编译产物里的这类片段也走这条路。
■ 两者协作
  编码到产物里的普通语句是机器码；动态片段（eval/命令替换）走解释器；
  两者共享同一份运行时（变量表、位置参数、重定向栈、trap 表、退出码）。

【8】内置模拟器
--------------------------------------------------------------------------------
  作用：在没有 qemu 的机器上运行/调试产物；也能用"虚拟文件系统覆盖层"
  观察产物到底写了什么文件。
  覆盖范围：通用寄存器指令集 + 常用 NEON/FP 子集 + 常用系统调用虚拟化。
  验证方式：382 条批量指令对拍（模拟器 vs 真机逐条比寄存器/内存），
  当前 381 条一致；唯一未实现的是 SIMD 单车道存储
  st1 {v?.b|h|s|d}[i], [xn]（同族的单车道装载已支持）。
  故障行为：默认自动回退到内嵌 qemu 从头重跑（--no-fallback / --emu-own 关闭回退）。
  调试开关：见【4】的 S2A_EMU_*。
  退出码：132 = 未实现指令，139 = 访存越界/段错误，124 = 步数上限。

【9】加固与加密内部
--------------------------------------------------------------------------------
■ 机制一：字符串池加密（-P / -F 的编译产物）
  · 字符串池 AES-256-CTR；密钥材料 = /dev/random 的 64 字节 seed，经
    kdf_strong() 域分离派生（purpose 标签 "protect-pool" / "protect-check"）。
  · 代码段与池各带 SHA-512 摘要，启动时自检。
  · 口令锁（--password）：密钥 = PBKDF2-HMAC-SHA256(口令, 盐 = 产物池前 16 字节,
    5000 次迭代) 派生 64 字节；每个产物的盐不同。口令不对 → 池解不开 → 70。
  · 注意：不带口令时 seed 就在产物里 —— 这是**混淆**，不是真加密。
■ 机制二：整文件加密（--only-enc）
  · 无口令：key = kdf_strong(seed, "onlyenc-seed", nonce)，seed/nonce 在尾部 → 混淆。
  · 有口令：key = PBKDF2-HMAC-SHA256(口令, 尾部随机盐, 5000 次) → 真加密 + 门禁，
    运行时不给口令直接 70，解密结果不是 ELF 也判 70。
  · 两者算法都是 AES-256-CTR；CTR 无认证，改密文只坏对应明文字节（不改也可能
    照样跑）→ 能防看，不防改。
■ 检测层（多层交叉验证，命中任意一层即计入）
  TracerPid（/proc/self/status）、/proc/self/maps 调试/注入特征、父进程名、
  环境预载（LD_PRELOAD/LD_AUDIT/S2A_DEBUG_TRACE）、断点/自校验、
  时序异常、/proc/stat 特征。
■ 为什么不会自锁
  早期实现在**主进程**里 ptrace(PTRACE_TRACEME)：这等于把父进程（shell/终端/
  任何已有 tracer）登记成 tracer，而它不会处理 ptrace 事件 → 本进程永远停在
  ptrace_stop，表现为"启动后 [1]+ Stopped、脚本只跑到一半"。现在：
    · 主进程绝不 TRACEME；
    · 主动探测只在 S2A_ANTIDEBUG_AGGRESSIVE=1 时做，且在**子进程**里做；
    · S2A_NO_ANTIDEBUG=1 在探测之前就返回（真正的逃生门）。
■ 误报处理
  安卓/终端环境 TracerPid≠0 是常态 → 默认 warn 一行不影响运行；
  要安静用 --anti-action silent；要彻底关用 S2A_NO_ANTIDEBUG=1。

【10】语言覆盖完全清单
--------------------------------------------------------------------------------
■ POSIX（目标：完整；308 条自检逐条与 bash/dash 对拍）
  口径：整个套件 308 条，产物与 bash 在 **303 条上完全一致**，余下 5 条是自检
  脚本自身写错（两边都不过），**没有任何一条是"只有产物失败"**。
  · 引用：单引号、双引号、反斜杠、$'…'、引号内换行、拼接
  · 参数展开：${v} ${#v} 与 ${v-…} ${v:-…} ${v=…} ${v:=…} ${v?…} ${v:?…}
    ${v+…} ${v:+…} ${v#p} ${v##p} ${v%p} ${v%%p}（含通配模式、最短/最长语义）
  · 特殊参数：$* $@ $# $? $- $$ $! $0 $1…$9（${1} 之类同样可用）
  · 算术：+ - * / % ** 括号 一元 位运算 移位 比较 逻辑 三目 逗号 | 赋值与
    复合赋值 前后自增自减 变量（可省 $）十六进制/八进制 命令替换参与运算
  · 命令替换：$( ) 与反引号，可嵌套，可包含 case 语句
  · 字段切分：IFS 全规则（空白合并、非空白分隔、$@/$* 特例、引号内不切分）
  · 路径名展开：* ? [ ]（含 [! ] 与范围），引号/转义元字符不参与展开
  · 重定向：< > >> <> >| n< n> n>&m n<&m n>&- << <<- <<< 复合命令重定向、
    重定向顺序敏感（2>&1 与 >x 2>&1 的差别）、错误退出码
  · 列表与管道：; & && || | ! 子 shell ( ) 分组 { }
  · 复合命令：if/elif/else/fi、for（含隐含 "$@"）、while/until、case（;; ;& ;;&）、
    break/continue（带层数）
  · 函数：定义、参数、return、递归、local、函数覆盖内建/外部命令
  · 特殊内建：: . eval exec exit export readonly return set shift times trap unset
  · 普通内建/工具：cd（-P -L CDPATH OLDPWD PWD）、command（-v -V -p）、echo、
    printf（%s %d %i %u %o %x %X %c %b %% 宽度/精度/*）、pwd、read（-r -d -n、
    IFS 切分、行继续）、test/[（! -a -o 括号 文件测试 字符串/数值比较）、
    getopts（聚合、参数、: 静默模式、OPTIND/OPTARG）、kill（信号名/编号 -l）、
    umask、wait、jobs、times、type、true/false
  · set 选项：-a -b -C -e -f -h -m -n -u -v -x，以及 -o 名字形式与 set +o 列表、
    set -- 清空位置参数
  · trap：信号名/编号、EXIT、'' 忽略、- 恢复默认、trap 内 exit 决定退出码、
    子 shell 不继承父 EXIT trap
  · 非交互语义：shell 自己忽略 SIGINT/SIGQUIT、子进程恢复默认处置；
    后台任务与前台同进程组（POSIX 非交互行为）
■ GNU 扩展（部分）
  支持：[[ ]] （字符串/数值/通配/正则，未加引号的右侧按模式匹配）、
        (( 算术命令 ))、$(( )) 里嵌 $( )、${v:off:len}、${v^} ${v^^} ${v,} ${v,,}、
        ${v/p/r} ${v//p/r} ${v/#p/r} ${v/%p/r}、${!v} 间接引用、${!prefix*}（部分）、
        $'…'、<<<、&> 与 &>>、函数覆盖内建
  不支持：数组与关联数组、shopt、{1..3} 花括号展开、bash 的 h/B 选项
■ 与 bash/dash 的已知差异（实测口径）
  · `$-` 只列本工具链真正支持的选项（没有 h/B）
  · `${#*}`/`${#@}` 取 $* 拼接后的长度（POSIX/dash 口径；bash 给参数个数）
  · `${#}` = $#（与 bash/dash 一致）
  · 不做作业控制（set -m）：POSIX 非交互行为

【11】内嵌工具（qemu / ash）—— 在 s2a 里，不在产物里
--------------------------------------------------------------------------------
  两个工具以 blob 形式链在 **编译器 s2a** 上（s2a 约 2.89MB），产物一律不带。
  调用方式：`s2a ash -c '…'`、`s2a ash 文件 参数…`、`s2a qemu …`；
  `s2a -r` 遇到未实现指令时也会自动用内嵌 qemu 兜底。
■ qemu-aarch64 静态版
  1,893,000 字节（UPX -9 压缩）。需要时解出到临时目录再执行
  （解出目录：$S2A_TOOL_DIR → $TMPDIR → /data/local/tmp → /tmp）。
  机器上已有 qemu-aarch64-static 时优先用它（除非 S2A_QEMU_FORCE_EMBEDDED=1）。
■ dash 0.5.12（真正的 ash）
  94,816 字节（UPX -9）。构建配方（可复现）：
    源码 http://gondor.apana.org.au/~herbert/dash/files/dash-0.5.12.tar.gz
    CC=musl-gcc CFLAGS="-Os -fno-asynchronous-unwind-tables -fno-unwind-tables
        -ffunction-sections -fdata-sections"
    LDFLAGS="-static -Wl,--gc-sections" ./configure --enable-static
    make && strip src/dash     → 198,320 字节
    upx -9 dash -o ash.upx     → 94,816 字节
  覆盖：POSIX 完整 + [[ ]] + 算术赋值；不支持 ${v:off:len}/${v^^}/${v//a/b}、
  source、{1..3}、echo -e（这些正是用 -easy 时需要留意的点）。
■ 分派协议
  s2a 启动先看 argv[1]：等于 "ash" 或 "qemu" 时，解出对应 blob 并以 argv[2..]
  执行它；其余情况按正常编译/运行流程走。产物侧不做任何分派。

【12】-easy 与 --only-enc 深挖
--------------------------------------------------------------------------------
■ -easy
  · 产物 = 外壳 + 内嵌 ash + 脚本正文（约 183KB）。
  · 完全不解析脚本：s2a 的语法支持范围与它无关，dash 能跑就能出产物。
  · 运行时：外壳把 ash 与脚本各解到临时目录（缓存 + 原子写），
    然后 exec `ash <脚本文件> <用户参数…>`（参数原样透传）。
  · 不做自己的脚本加密 —— 需要保护就交给 --only-enc（同一套加密逻辑）。
■ --only-enc
  · 输入任意 ELF，输出 = 外壳 + AES-256-CTR 密文 + 128 字节索引。
  · 不给口令：key = kdf_strong(seed, "onlyenc-seed", nonce)，seed/nonce 在尾部 → 混淆。
  · 给口令：key = PBKDF2-HMAC-SHA256(口令, 尾部随机盐, 5000 次)，pw_flag=1 → 门禁；
    运行 `./out.enc` **必须**再给同一口令（--password / --password-env /
    --password-file / S2A_PASSWORD），否则 70；外壳会把这些口令参数取走，
    不传给内部程序。
  · 运行时：读自身尾部 → 解密到匿名内存页（memfd）→ fexecve，argv 原样透传；
    memfd 受限时兜底落盘 exec 并清理（S2A_NO_MEMFD=1 可强制走落盘路径）。
  · 组合：s2a -easy -o a.elf s.sh && s2a --only-enc a.elf a.enc
    （加密后的 easy 产物照常工作，已实测）
  · 嵌套：外层加密之后可以再加密一次（可多层）。外层解出口令会导出 S2A_PASSWORD
    给内层，且只吃第一个口令参数（后续留给内层）→ 内层带口令锁时也能解开。
    同口令：给一次即可；不同口令：`./x.enc --password 外层 --password 内层`。
  · 示例：s2a --only-enc a.elf a.enc --password 'mypw'

【13】体积与性能
--------------------------------------------------------------------------------
  · 普通产物：约 450KB（典型 451,008 字节量级；只含你编译进去的脚本与运行时
    模板，**不带任何工具**）。
  · -easy 产物：约 183KB（外壳 88,184 + ash 94,816 + 脚本 + 128）。
  · --only-enc 产物：外壳 88,184 + 原文件大小 + 128 字节。
  · 工具不在产物里：qemu 1,893,000 + ash 94,816 只占 s2a 自己的体积
    （bin/s2a 约 2.89MB；strip 后 bin/s2a-s 约 2.84MB）。
  · -s 去符号表、-O4 让机器码更紧凑，都能再小一些。
  · 运行期开销：编译产物几乎没有解析开销（启动即执行）；
    命令替换/eval 这类动态片段才有解析成本。
  · 编译速度（本机实测参考）：简单脚本编译约几十毫秒量级；加 -P/-F 后启动时
    多一次 SHA-512 自检与池解密，属毫秒量级。

【14】故障排查手册
--------------------------------------------------------------------------------
  症状：启动后 [1]+ Stopped，或脚本只跑到一半就停住
  原因：旧产物在"已被 tracer 占用"的环境里 ptrace 自锁。
  处置：用本版重建产物；临时应急 S2A_NO_ANTIDEBUG=1（本版连探测都不做）。
  ----------------------------------------------------------------------------
  症状：退出码 70
  原因：产物带口令锁，没给/给错 --password；或 --only-enc 解出来不是 ELF。
  ----------------------------------------------------------------------------
  症状：`s2a ash -c '…'` / `s2a qemu …` 报 73 或"解不出内嵌工具"
  原因：没有可写目录。
  处置：S2A_TOOL_DIR=/data/local/tmp 后重试。
  ----------------------------------------------------------------------------
  症状：想用 `./产物 ash -c '…'`
  原因：做不到 —— 产物里没有 ash。（工具索引在早期版本有，现已移除）
  处置：改用 `s2a ash -c '…'`；要产物自带解释器就用 -easy（内含 dash）。
  ----------------------------------------------------------------------------
  症状：退出码 132
  原因：模拟器遇到未实现指令（多见于 --emu-own 或 --no-fallback）。
  处置：去掉这两个开关让它自动回退 qemu；或把出问题的产物/指令反馈。
  ----------------------------------------------------------------------------
  症状：退出码 139
  原因：模拟器判定访存越界/段错误（这是"贴近内核严格面"的设计）。
  处置：确属合法写法时用 S2A_EMU_NO_SEGCHECK=1 / S2A_EMU_NO_HOLECHECK=1 放行。
  ----------------------------------------------------------------------------
  症状：退出码 124
  原因：模拟器步数上限（默认 3000 万步，防跑飞）。
  处置：确认不是死循环；确实需要更长就调 S2A_EMU_MAX_STEPS。
  ----------------------------------------------------------------------------
  症状：反调试一直打印 TracerPid 警告
  原因：安卓终端/root 环境常见，属误报。
  处置：--anti-action silent，或运行时 S2A_NO_ANTIDEBUG=1。
  ----------------------------------------------------------------------------
  症状：memfd 执行被内核拒绝
  处置：无需处理，外壳会自动兜底落盘执行；也可用 S2A_TOOL_DIR 指定目录。
  ----------------------------------------------------------------------------
  症状：产物体积太大
  处置：-s（strip）、-O4，或改用 -easy（约 183KB）。
      注意 --no-tools 现已无作用（产物本来就不带工具），别指望它省体积。

【15】退出码一览
--------------------------------------------------------------------------------
  0        成功（运行模式下 = 脚本自身退出码）
  1–125    脚本自身退出码；编译模式下 1 = 编译失败
  2        用法错误
  70       口令缺失/错误（含 --only-enc 解出来不是 ELF）
  73       解不出内嵌工具（没有可写目录）
  124      模拟器步数上限
  126      命令不可执行（含 s2a ash/qemu 解出后 execv 失败）
  127      命令未找到（与 POSIX 一致）
  132      模拟器遇到未实现指令（--emu-own / --no-fallback 时）
  139      访存越界/段错误（模拟器判定）
