铸壳工具链（ForgeShell）· s2a —— 快速参考（-h）
================================================================================
把 shell 脚本编译成 aarch64 纯静态 ELF：无 PT_INTERP、无 .dynamic、自带 musl
运行时，拷到任何 aarch64 Linux/Android 上直接跑。
自带 AArch64 模拟器、qemu 与 dash —— 这三样**只装在 s2a 里，产物里没有**。

常用命令
  s2a [选项] <脚本>                     编译脚本
  s2a [选项] -e '<脚本内容>'            编译一段文本
  s2a -r <产物> [参数…]                 用内置模拟器执行产物
  s2a ash -c '命令'                     s2a 自带 dash 执行命令（产物没有这个）
  s2a qemu -L … ./prog                  s2a 自带 qemu 执行别的 aarch64 程序
  s2a -h | --help | --help-full         帮助（快 / 常用 / 完整）
  s2a --help-dev                        构建、自检与开发笔记
  s2a -v | --version / -license         版本 / MIT 许可证

三种产物（普通与 --only-enc 都不含工具；-easy 自带一份 dash 才能解释执行）
  普通编译    约 450KB   生成的机器码 + 运行时常量（只含你的脚本）
  -easy       约 183KB   外壳 + 内嵌 dash + 脚本正文，不做编译
  --only-enc  外壳 88,184 + 原文件长度 + 128 字节 的整文件加密产物

一条分界（最重要，先记住）
  不给口令 = 混淆：密钥原料就在文件里，防的是 strings／顺手一看／特征扫描。
  给口令   = 真加密：--password / --password-env / --password-file / S2A_PASSWORD，
             密钥离开文件（PBKDF2-HMAC-SHA256），运行时必须再给同一口令。

常用选项
  -o <文件>   -e '<文本>'   -s（strip）   -K（留中间产物）
  -O0 … -O4   -g1 … -g5（-g5 最详细）
  -P          字符串池 AES-256-CTR 加密 + SHA-512 自检 + 反调试
  -F          最全保护（等级 3 + 优化 4）
  --password '<口令>' / --password-env <变量> / --password-file <文件>
  --anti-action  warn(默认) | report | silent | fake | delay | stop
  -easy                        最简模式（外壳 + dash + 脚本）
  --only-enc <in> <out>        整文件加密（给口令就是运行期门禁）
  -r / -qemu / --emu-own / --no-fallback / --emu-trace
  -X | --iso                   交给外部 iso 项目执行

退出码
  0 成功 | 2 用法错误 | 70 口令缺失/错误 | 73 解不出内嵌工具
  124 模拟器步数上限 | 126 不可执行 | 127 命令未找到
  132 未实现指令 | 139 访存故障
  其余 1–125 = 脚本自身退出码；编译模式下 1 = 编译失败

再往下看
  --help        常用选项、环境变量、三种产物、加密机制、语言覆盖、退出码、已知缺陷
  --help-full   完整手册：字节布局、尾部 128 字节字段表、运行时架构、模拟器、
                加固内部、语言覆盖完全清单、体积性能、故障排查
  --help-dev    构建（make / 资源清单）、自检与回归怎么跑、待办与开发笔记
